

# 🧠 Text Classification Using RNN and LSTM

## 📘 Overview

This project demonstrates how to build and train Recurrent Neural Networks (RNN) and Long Short-Term Memory (LSTM) models for text classification. It processes textual data, performs preprocessing, and classifies text into predefined categories using deep learning techniques in TensorFlow and Keras.

---

## 📂 Project Structure

### Notebook: `Text_Classification_Using_RNN_and_LSTM.ipynb`

Key components of the notebook:

1. **Data Loading & Exploration**

   * Loads a text classification dataset (e.g., IMDb, news, or custom).
   * Analyzes class distribution and sample data.

2. **Text Preprocessing**

   * Tokenization
   * Padding sequences
   * Vocabulary size selection

3. **Model Building**

   * Simple RNN-based model
   * LSTM-based model
   * Custom embeddings or pretrained embeddings (if applicable)

4. **Training & Evaluation**

   * Model compilation and training
   * Performance evaluation using accuracy and loss
   * Optional: confusion matrix or F1-score for deeper insight

5. **Results Visualization**

   * Accuracy and loss curves
   * Insights into overfitting/underfitting behavior

## 🎯 Objective

* Understand the workings of RNNs and LSTMs for sequential data.
* Compare performance of simple RNN vs LSTM on a real-world classification task.
* Learn preprocessing steps required for feeding text data to neural networks.

## 📈 Expected Outcome

* A trained LSTM model for text classification.
* Performance metrics and visual analysis of training behavior.
